# Levels (paths relative to the Unity project `3DTD/`)

## Level tooling
- Level tooling (`Assets/Editor/LevelTools/`, batch-mode entry points, project closed in the Editor):
  - `BeginnerLevelBuilder.Run` (also menu 3DTD > Levels > Rebuild Beginner Levels) generates Beginner Level 02-05: it copies the `Beginner Level 01` scene, swaps its map for a generated `Prefabs/Maps/BeginnerLevel0X.prefab` (Level 01's track tiles laid along a path DSL, a nested `SpawnerNew`, `EndNew`, waypoints, starter blocks), sets the camera anchor and distance, rewrites the build list and re-bakes the level catalog. The maps are defined in code there; edit the builder, not the scenes or map prefabs. Rebuilding drops the Spawner wave lists, so run `write_waves.py` and `extract.py` afterwards.
  - `LevelPlaytest.Run` (needs graphics) plays wave 1 of every beginner level undefended (checks that the lane reaches the exit), then builds the level's featured tower through the anchor build path and checks it deals damage. It writes three screenshots per level to `tasks/levels/screenshots/` (or `-captureOut <dir>`) and exits with the number of failed checks (`LEVELTEST PASS|FAIL`). It backs up and restores progress and savegame.

## Beginner level designs
Beginner Level 01 is hand-built; 02-05 are generated by `BeginnerLevelBuilder` (single lane each, one 3D idea and one favoured strategy per map, tuned with the balance tools):
- 02 Ring Road: the lane circles the whole map with a raised far half; starter blocks only in the middle. Long range (Sniper, then Hangar). Its waves skip armor checks (projectile-only reach) and grow slower.
- 03 Back to Back: two folded stacks (slab top, wrap, upside down underneath, floor), starter blocks between them. Close quarters and splash (Mine Factory, Rockets, Hangar). Swarm waves.
- 04 Upside Down: long upside-down straights under a canopy and a 6 unit shaft; starter blocks in line with the straights, so their bottom faces carry Beam Towers firing down a straight. Dense waves.
- 05 Corkscrew: a square helix around a central pillar, 4 units out and 3 units per turn. Hangar (all-round reach from the pillar); short range barely reaches. Swarm waves.
